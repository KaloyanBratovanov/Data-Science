# Data Science

My Data Science exercises and projects using Python.

## Projects

### 01 - Working with Data

Data cleaning, exploration and analysis of Anime and Manga datasets from Kaggle.

Topics covered:
- Pandas and data manipulation
- Missing values and data types
- Data cleaning and validation
- Grouping and aggregation
- Ratings and popularity analysis
- Text normalization
- Combining datasets
- Exporting cleaned data

Dataset: https://www.kaggle.com/datasets/andreuvallhernndez/myanimelist

## Technologies

Python, Pandas, Jupyter Notebook
